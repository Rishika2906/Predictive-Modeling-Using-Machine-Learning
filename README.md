# Predictive Modeling Using Machine Learning

## Project Overview

This project demonstrates a Machine Learning classification model that predicts whether a person has heart disease using medical data.

The model is built using the Random Forest Classifier and evaluated using Accuracy, Classification Report, and Confusion Matrix.

## Objective

- Build a predictive Machine Learning model
- Train and test the model
- Evaluate model performance
- Visualize performance using a Confusion Matrix

## Dataset

- Heart Disease Dataset (heart.csv)

## Algorithm Used

- Random Forest Classifier

## Libraries Used

- pandas
- scikit-learn
- matplotlib

## Project Workflow

1. Import Libraries
2. Load Dataset
3. Explore Dataset
4. Separate Features and Target Variable
5. Split Data into Training and Testing Sets
6. Train the Random Forest Model
7. Make Predictions
8. Calculate Accuracy
9. Generate Classification Report
10. Display Confusion Matrix

## Results

- Accuracy: **98.54%**
- Model: Random Forest Classifier

The model successfully predicts heart disease with high accuracy.
